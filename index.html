Your data saves to portfolio_data.json in your Google Drive and syncs across every browser and device automatically.

2
Go to APIs & Services → Credentials → Create OAuth 2.0 Client ID (Web Application). Under "Authorized JavaScript origins" add your GitHub Pages URL e.g. https://yourname.github.io.
3
Create an API Key under Credentials too. Paste both below.
